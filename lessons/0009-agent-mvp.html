2. CLI 交互循环：从 one-shot 到持续对话

你现在的 main.ts 是硬编码几个 await run(...) 顺序执行。 MVP 需要一个交互式 read-eval-print loop (REPL)：用户在终端持续输入，Agent 持续应答，按 Ctrl+D 退出。 

import * as readline from 'node:readline';

const rl = readline.createInterface({
  input: process.stdin,
  output: process.stdout,
  prompt: '你: ',
});

rl.prompt();
rl.on('line', async (line) => {
  const input = line.trim();
  if (!input) { rl.prompt(); return; }

  const { summary, history } = await session.load();
  const result = await runAgent({ client, input, registry, options, summary, conversation: history });
  await session.save(result.conversation);

  console.log(`\nAgent: ${result.outputText}\n`);
  rl.prompt();
});

这 10 行代码就是 MVP 的交互入口。它串起了 session → loop → session 的完整流程。 不需要框架，不需要 UI 库，就是一个终端 REPL。

产品细节：加上 /exit、/clear 等命令可以让体验更完整， 但 MVP 阶段优先保证核心对话流程稳定。额外命令是锦上添花。

3. 三个用户故事 —— 你的 MVP 必须能讲

MVP 不是"所有功能都做完"，是三个完整的端到端用户故事能跑通。 每个故事 = 用户的自然语言输入 → Agent 多步推理 + 工具调用 → 有用的输出。

故事 1

快速记录

"帮我把买牛奶、写周报、周四开会加到待办里"
→ Agent 添加 3 条 → 确认完成并列出摘要

故事 2

回顾与操作

"我刚才加了什么？把写周报标为完成，然后列出所有还没做的事"
→ 回忆历史 → 标记完成 → 列出 pending

故事 3

规划和清理

"帮我规划下周任务，清理掉重复的，按优先级排一下"
→ 先列出全部 → 分析去重 → 添加新增 → 给出计划

面试叙事：不要只 demo 功能。说："我的 MVP 覆盖三条用户故事—— 快速录入、上下文回顾、规划清理。每条故事都经过至少 2 步工具调用， 验证了 loop / session / 工具编排的协作。这里有 eval 回归结果，9 条全绿。"

4. README：让陌生人十分钟跑通

课程的 L9 验收标准写得很清楚：陌生人按 README 能在 10 分钟内跑通一个完整任务。 README 不是文档，是新用户的 onboarding 路径。

README 最少要有的六个小节：

  1. 一句话：这是什么 — "个人任务管家 CLI，用自然语言管理待办事项"
  2. 前置条件 — Bun, Node 模块, .env 配置 (GODEX_BASE_URL)
  3. 安装 — bun install
  4. 运行 — bun run src/main.ts
  5. 演示（3 条用户故事） — 逐条附输入/输出截图或文字
  6. 跑评测 — bun run eval/suite.ts
README 放在项目根目录 README.md。以后面试时把 repo 链接发给面试官， 对方打开 README 五分钟内就能理解你做了什么——这比你在面试中口头描述强十倍。

6. 练习

以下练习只描述目标，代码由你实现。

  1. CLI REPL：改造 main.ts，用 node:readline 实现交互式对话循环。 用户输入一条消息 → Agent 处理并输出结果 → 等待下一条输入。Ctrl+C 两次退出。
  2. 三个用户故事验证：按第 3 节的三条故事，在 REPL 中逐条跑通。 确认每条故事都涉及 ≥2 步工具调用，session 在多轮间正确衔接。
  3. README.md：在项目根目录写 README。包含第 4 节列出的六个小节， 截取终端录屏或关键输出作为演示证据。
验收检查清单：① 别人 clone 仓库后按 README 三步能跑起来 ② 三条用户故事逐条演示无报错 ③ 关闭终端重开，对话能继续 ④ bun run eval/suite.ts 全绿。 四条全过，MVP 就合格了。
