Lesson 0005 · L6 核心

工具注册表与错误工程：从 switch-case 到可插拔轨道

L5 的 Agent Loop 跑通了，但工具还挂在 FunctionCalling.ts 的一个 switch 里。 每加一个工具就要改 executeTool，参数校验靠 JSON.parse 裸奔， 工具崩了 Agent 直接挂。这一课把工具变成可插拔模块，并让错误变成模型的输入而非程序的终点。

约 15–20 分钟 前置：L5 Agent Loop 术语表 工具设计速查

1. 当前问题：switch-case 的尽头

你现在的 executeTool 长这样（FunctionCalling.ts:55-62）：

export const executeTool = async (functionCall) => {
  const params = JSON.parse(functionCall.arguments);  // ← 如果 arguments 格式不对呢？
  switch (functionCall.name) {
    case 'get_weather': return getWeather(params.city);  // ← 如果 city 不存在呢？
    case 'get_horoscope': return getHoroscope(params.sign);
    default: throw new Error(`Unknown tool: ${functionCall.name}`);  // ← 抛异常，Agent 崩
  }
}

三个问题：

  • 不可扩展：每加一个工具都要改这里
  • 不防错：参数缺失/类型错误直接抛异常
  • 不可恢复：throw 吞掉错误，模型不知道发生了什么

解决办法：工具注册表（Tool Registry）——一个集中管理所有工具的容器， 负责注册 schema、分发调用、统一错误处理。

2. 工具注册表：设计

每个工具是一个对象

interface Tool {
  schema: OpenAI.Responses.Tool;      // 给模型看的定义
  execute: (args: Record<string, unknown>) => Promise<string>;  // 你的执行函数
}

注册表做三件事

职责方法谁调用
注册工具 register(tool) 你初始化时
暴露 schemas getSchemas() Agent Loop 创建请求时
执行工具 execute(name, args) Agent Loop 收到 function_call 时
核心原则：工具执行永远不抛异常。 成功返回结果字符串，失败返回错误描述字符串——两种都是给模型看的内容。 模型收到 "Error: file not found" 后可以自己决定重试、换参数、或告诉用户。

3. 第一个真工具：Todo CRUD

用本地 JSON 文件做存储（todos.json），提供 4 个操作：

工具名参数功能
todo_addtitle, description?添加待办，返回新增任务的 id
todo_liststatus?列出待办，可按状态筛选
todo_completeid标记待办为已完成
todo_deleteid删除待办

每个工具的执行逻辑都一样：

  1. 校验参数（类型、必填）
  2. 读写 todos.json
  3. 成功返回描述字符串 / 失败返回 "Error: ..."

4. 错误转信息：模型的"第二双眼"

比较两种错误处理：

throw（坏） 
if (!params.title) {
  throw new Error('Missing title');
}
// Agent 崩了，不知道原因
return error string（好） 
if (!params.title) {
  return 'Error: title is required';
}
// 模型收到错误，可以：
// "I need a title. What task do you want to add?"

返回错误字符串后，Agent Loop 照常把它作为 function_call_output 传给模型。模型看到错误后自己决定下一步——这正是 Agent 自主性的体现。

注意：不是所有错误都应该给模型看。内部错误（文件系统崩溃、内存不足） 可以 catch 后返回一个模糊的描述 + 记日志，避免泄露系统细节。

5. Loop 接入注册表

loop.ts 只需改两处：用 registry.getSchemas() 替代硬编码的 tools 数组，用 registry.execute(name, args) 替代 executeTool(functionCall)。 

// Before
const response = await client.responses.create({ tools, /* ... */ });
const output = await executeTool(functionCall);

// After
const response = await client.responses.create({
  tools: registry.getSchemas(), /* ... */
});
const output = await registry.execute(functionCall.name, JSON.parse(functionCall.arguments));
