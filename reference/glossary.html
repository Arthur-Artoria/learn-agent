Agent 术语表

本课程统一用语。所有 lesson 以此为准，避免「Agent / Workflow / Tool」混用。

术语 定义（本课程）
Model 负责推理与生成的 LLM；通过 Responses API 调用。
Tool / Function 模型可请求执行的外部能力；由你的代码真正运行并回传结果。
Tool call 模型输出的「请调用某工具 + 参数」；尚未执行。
Tool result 你执行工具后回写给模型的输出（如 function_call_output）。
Agent Loop 重复「模型 →（可选）工具 → 回填」直到得到最终答复或触达限制。
Workflow 步骤基本固定的编排（A→B→C）；比 Agent 更可预测，自治更少。
Instructions 对模型行为的稳定约束（角色、边界、输出风格）。
Structured output 按 schema（如 Zod）约束的模型输出，便于程序消费。
Session / Memory 跨轮次保留的状态；短期对话历史与长期记忆是不同层级。
Guardrail 防止失控的约束：步数上限、超时、权限、输出校验等。
Trajectory 一次 run 中模型与工具的完整轨迹，用于调试与评测。
previous_response_id Responses API 用上一响应 ID 衔接多轮，减少手动拼 history。
